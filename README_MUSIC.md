# 音乐播放器使用说明

## 功能特性

- 🎵 精美的音乐播放器界面
- 🎨 渐变背景和毛玻璃效果
- 📱 响应式设计，支持移动端
- 🎹 播放列表功能
- 🔊 音量控制
- ⏯️ 播放/暂停、上一首/下一首
- 📊 进度条和时间显示
- 🎶 波形动画效果

## 安装步骤

### 1. 准备音乐文件

将音乐文件放入 `app/static/music/` 目录：

```bash
mkdir -p app/static/music
# 将你的音乐文件（.mp3, .wav, .ogg, .m4a, .flac）复制到此目录
```

### 2. 文件命名规则

推荐的文件命名格式：
- `艺术家 - 歌曲名.mp3` （例如：`Taylor Swift - Love Story.mp3`）
- 如果不包含 " - "，文件名将作为歌曲标题，艺术家显示为"未知艺术家"

### 3. 启用音乐播放器

在 `.env` 文件中设置：

```env
ENABLE_BACKGROUND_MUSIC=True
```

或者直接在 `app/config.py` 中修改：

```python
ENABLE_BACKGROUND_MUSIC = True
```

### 4. 支持的音频格式

- MP3 (.mp3)
- WAV (.wav)
- OGG (.ogg)
- M4A (.m4a)
- FLAC (.flac)

## 使用说明

1. **播放/暂停**：点击播放按钮
2. **上一首/下一首**：点击相应的按钮
3. **调整进度**：点击进度条上的任意位置
4. **调整音量**：点击音量滑块
5. **查看播放列表**：点击播放列表按钮
6. **选择歌曲**：在播放列表中点击歌曲名称

## 界面说明

播放器位于页面顶部，包含：
- 控制按钮（上一首、播放/暂停、下一首）
- 歌曲信息（标题和艺术家）
- 波形动画（播放时显示）
- 进度条和时间显示
- 音量控制
- 播放列表按钮

## 技术实现

- **前端**：HTML5 Audio API + JavaScript
- **样式**：CSS3（渐变、动画、响应式）
- **后端**：Flask API 路由 (`/api/music/list`)
- **文件服务**：Flask 静态文件服务

## 注意事项

1. 音乐文件需要放在 `app/static/music/` 目录
2. 确保文件权限正确（可读）
3. 大型音乐文件可能影响加载速度
4. 浏览器自动播放策略可能限制自动播放（需要用户交互）

## 故障排查

1. **播放器不显示**：检查 `ENABLE_BACKGROUND_MUSIC` 配置
2. **没有音乐**：检查 `app/static/music/` 目录是否有音乐文件
3. **无法播放**：检查浏览器控制台错误信息
4. **文件格式不支持**：确保使用支持的音频格式
