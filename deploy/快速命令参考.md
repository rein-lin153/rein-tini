## 🚀 部署命令

```bash
# 一键部署
cd /home/opc/rein-tini && bash deploy/deploy.sh

# 创建管理员
cd /home/opc/rein-tini && source venv/bin/activate && python scripts/create_admin.py

# 启动服务
sudo systemctl start heartmoments
sudo systemctl restart nginx

# 开机自启
sudo systemctl enable heartmoments
sudo systemctl enable nginx
```

**提示**：将常用命令保存为 alias，添加到 `~/.bashrc`：

```bash
# 编辑 .bashrc
nano ~/.bashrc

# 添加以下内容
alias hm-status='sudo systemctl status heartmoments'
alias hm-restart='sudo systemctl restart heartmoments'
alias hm-log='tail -f /home/opc/rein-tini/logs/gunicorn-error.log'
alias hm-cd='cd /home/opc/rein-tini && source venv/bin/activate'
alias hm-update='cd /home/opc/rein-tini && git pull && source venv/bin/activate && pip install -r requirements.txt && sudo systemctl restart heartmoments'

# 重新加载
source ~/.bashrc
```

使用示例：
```bash
hm-status    # 查看状态
hm-restart   # 重启服务
hm-log       # 查看日志
hm-cd        # 进入项目目录并激活虚拟环境
hm-update    # 更新并重启
```
